## Download & Install

> Setup notes for **Glary File Recovery** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Glary File Recovery** from the Start menu

## What you can use it for

- Scan drives for deleted or lost files
- Preview recoverable items before restoring
- Deep scan modes for formatted partitions
- Recovery from USB, SSD, HDD, and SD cards
- Export restored files to a safe destination
